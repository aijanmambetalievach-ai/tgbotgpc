# Бесплатный запуск бота: Render + Neon

Весь запуск бесплатный и без банковской карты. Займёт примерно 30 минут.

| Что | Где | Бесплатно |
|---|---|---|
| Бот (сервер) | [Render](https://render.com) | 750 часов в месяц: хватает на один бот 24/7 |
| База данных | [Neon](https://neon.tech) | Хватает для тысяч клиентов и заявок |
| «Будильник» | [UptimeRobot](https://uptimerobot.com) | Не даёт серверу засыпать |

> Бесплатный сервер Render засыпает через 15 минут без запросов. Telegram сам
> будит его новым сообщением, но первый ответ после сна приходит примерно через
> минуту. UptimeRobot раз в 5 минут «стучится» в бот, и тот не засыпает.

---

## Шаг 1. Токен бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя (например, «Тендер Академия») и username, который
   заканчивается на `bot` (например, `tender_academy_kg_bot`).
3. Скопируйте **токен**: строку вида `1234567890:AAH...`. Никому его не показывайте.
4. Там же отправьте `/setcommands`, выберите бота и вставьте:

   ```
   start - Главное меню
   help - Что умеет бот
   cancel - Отменить текущее действие
   ```

## Шаг 2. Ваш Telegram ID

Откройте [@userinfobot](https://t.me/userinfobot) и нажмите Start. Он пришлёт
число `Id`, например `123456789`. Такие же числа понадобятся от каждого
консультанта, который будет отвечать клиентам.

## Шаг 3. База данных в Neon

1. Зарегистрируйтесь на [neon.tech](https://neon.tech): удобнее всего через
   Google или GitHub.
2. **Create project**: имя любое, например `tender-bot`. **Region**:
   **AWS Europe Central 1 (Frankfurt)**, ближе всего к Render.
3. Нажмите **Connect** («Подключиться»). Переключатель **Connection pooling**
   («Пул соединений») можно оставить как есть: бот работает с обоими вариантами.
4. Нажмите **Copy snippet** («Скопировать фрагмент»). Строка выглядит так:

   ```
   postgresql://neondb_owner:пароль@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require&channel_binding=require
   ```

   Строку можно вставлять как есть: бот сам приведёт её к нужному виду.

## Шаг 4. Бот на Render

> Код бота должен быть в ветке **main** репозитория `tgbotgpc`. Если новая
> версия ещё в отдельной ветке, сначала примите запрос на слияние (Pull request)
> на GitHub.

1. Зарегистрируйтесь на [render.com](https://render.com) через **GitHub** и
   разрешите доступ к репозиторию `tgbotgpc`.
2. **New** → **Blueprint** → выберите репозиторий `tgbotgpc`. Render найдёт
   файл `render.yaml`.
3. Render попросит три значения:

   | Поле | Что вписать |
   |---|---|
   | `BOT_TOKEN` | токен из шага 1 |
   | `BOOTSTRAP_ADMIN_TELEGRAM_IDS` | ваш ID из шага 2; несколько ID — через запятую: `123456789,987654321` |
   | `DATABASE_URL` | строка из шага 3 |

4. Нажмите **Apply**. Первая сборка занимает 5–10 минут.
5. Когда статус станет **Live**, откройте вкладку **Logs**. В логах должна быть
   строка `webhook registered`.
6. Вверху страницы сервиса есть адрес вида
   `https://tender-training-bot-xxxx.onrender.com`. Он пригодится в шаге 5.

**Проверка:** напишите своему боту `/start`. Должно прийти приветствие
администратора и админ-меню.

## Шаг 5. «Будильник» UptimeRobot

1. Зарегистрируйтесь на [uptimerobot.com](https://uptimerobot.com) (бесплатный план).
2. **New monitor** → тип **HTTP(s)**.
3. URL: адрес из шага 4 с добавкой `/health`, например
   `https://tender-training-bot-xxxx.onrender.com/health`.
4. Интервал: **5 minutes** → **Create monitor**.

Бонус: если бот упадёт, UptimeRobot пришлёт письмо.

## Шаг 6. Наполнить бот

В админ-меню бота:

1. **⚙️ Настройки** → «О нас» и «Контакты».
2. **❓ FAQ**: 5–10 частых вопросов.
3. **🗓 Курсы** → создать курс → «🟢 Опубликовать».
4. **⚙️ Настройки → 📸 Ссылки для Instagram**: поставьте ссылки в шапку профиля и в сторис.

---

## Как обновлять

Каждое изменение в ветке `main` на GitHub Render выкладывает сам, за 5–10 минут.
Данные в базе при этом сохраняются. Незаконченные диалоги (клиент начал заявку,
но не отправил) при обновлении сбрасываются.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Бот молчит | Render → **Logs**. Ошибка `Unauthorized` — неверный `BOT_TOKEN` (Environment → исправить → Save) |
| В логах ошибка подключения к БД | `DATABASE_URL` скопирован целиком, без пробелов и переносов строк |
| Нет админ-меню | Ваш ID есть в `BOOTSTRAP_ADMIN_TELEGRAM_IDS`. После правки нажмите **Manual Deploy** |
| Бот отвечает через минуту | Сервер спал: проверьте монитор в UptimeRobot |

## Ограничения бесплатного варианта

- **Render:** 512 МБ памяти и 750 часов в месяц. Для одного бота этого хватает с
  запасом, если не запускать на том же аккаунте другие бесплатные сервисы.
- **Neon:** бесплатного объёма хватит на тысячи клиентов и заявок. Видео и файлы
  уроков хранятся в Telegram и место в базе не занимают.
- **Когда бот вырастет**, переход на платный план Render (около $7 в месяц)
  делается одной кнопкой, без переделки кода. Сон пропадёт, «будильник» станет
  не нужен.
- Бесплатные условия сервисов могут меняться. Актуальные условия: на
  [render.com/docs/free](https://render.com/docs/free) и [neon.tech/pricing](https://neon.tech/pricing).
